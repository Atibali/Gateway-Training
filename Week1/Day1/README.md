# MyFirstApp

Small C# lesson demos. Requires the .NET 10 SDK.

## Run

```sh
dotnet run
dotnet run -- Methods
```

Replace `Methods` with `HelloWorld`, `TypesAndVariables`, `TypeConversion`, `Operators`, `Strings`, `Collections`, or `ControlFlow`.

## Topics

C# basics, types and conversion, operators, control flow, methods, strings, and collections.
