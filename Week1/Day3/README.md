# Day 3: Object-Oriented Programming

Day 3 contains C# Object-oriented programming examples covering classes and objects, encapsulation, inheritance, polymorphism, and abstraction. The examples require the .NET 10 SDK.

## C# examples

From the repository root, run one example at a time:

```sh
dotnet run --file Week1/Day3/Abstraction.cs
```

Replace `Abstraction.cs` with the example you want to run:

| Program | Topic |
|---|---|
| `ClassesAndObjects.cs` | Classes, objects, constructors, and properties |
| `Encapsulation.cs` | Encapsulating bank account data and operations |
| `Inheritance.cs` | Base and derived classes, and method overriding |
| `Polymorphism.cs` | Method overloading, overriding, and hiding |
| `Abstraction.cs` | Abstract classes and interfaces |
