# Day 3: Object-Oriented Programming

Day 3 contains C# examples covering object-oriented programming and SOLID principles. The examples require the .NET 10 SDK.

## C# examples

From the repository root, run one example at a time:

```sh
dotnet run --file Week1/Day3/ClassesAndObjects.cs
```

Replace `ClassesAndObjects.cs` with the example you want to run:

| Program | Topic |
|---|---|
| `ClassesAndObjects.cs` | Classes, objects, constructors, and properties |
| `StructsAndRecords.cs` | Structs and records |
| `StaticMembers.cs` | Static fields, properties, and methods |
| `Encapsulation.cs` | Encapsulation of data and behavior |
| `Inheritance.cs` | Inheritance and method overriding |
| `MultilevelInheritance.cs` | Multilevel inheritance |
| `HierarchicalInheritance.cs` | Hierarchical inheritance |
| `MultipleInheritance.cs` | Multiple inheritance using interfaces |
| `Hybrid.cs` | Hybrid inheritance using classes and interfaces |
| `Polymorphism.cs` | Method overloading, overriding, and hiding |
| `Abstraction.cs` | Abstract classes and interfaces |
| `Composition.cs` | Composition between classes |
| `SRP.cs` | Single Responsibility Principle |
| `OCP.cs` | Open/Closed Principle |
| `LSP.cs` | Liskov Substitution Principle |
| `ISP.cs` | Interface Segregation Principle |
| `DIP.cs` | Dependency Inversion Principle |
