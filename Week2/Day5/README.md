# Week 2 · Day 5 — QA Training

## Topics Covered

### 1. Jira – Project & Issue Management
- Jira projects, issue types (Epic, Story, Task, Bug and Sub-task).
- Workflows, Scrum and Kanban boards.
- Filters and basic JQL queries for tracking issues.

### 2. Test Management
- Introduction to Xray and Zephyr.
- Creating and organizing test cases.
- Test Sets and Test Executions.
- Recording Pass, Fail and Blocked results.

### 3. Chrome DevTools
- Inspecting browser Console errors and warnings.
- Network tab and Fetch/XHR requests.
- Understanding HTTP status codes, request headers and responses.
- Exporting HAR files for debugging.

### 4. Bug Evidence & Defect Reporting
- Capturing screenshots and screen recordings.
- Understanding defect report structure.
- Severity vs Priority and defect lifecycle.
- Preparing structured bug reports with reproduction steps and evidence.

### 5. Software Testing Techniques
- **Equivalence Partitioning (EP):** Dividing inputs into valid and invalid groups.
- **Boundary Value Analysis (BVA):** Testing minimum, maximum and boundary values.
- **Decision Table Testing:** Testing combinations of conditions and expected actions.

### 6. Practical Exercises
- Prepared HelpDesk test cases using EP, BVA and Decision Tables.
- Created five sample bug reports for a HelpDesk application.
- Practiced documenting expected results, actual results, severity and priority.
