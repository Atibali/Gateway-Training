# Week 2: Day 2 - HTML, CSS, Forms, and Accessibility

Day 2 focused on building well-structured, responsive, and accessible web pages using HTML and CSS. The exercises in this folder cover the basics of semantic markup, form design, layout systems, and accessible content practices.

## Topics covered

### HTML and document structure

- Create a complete HTML document using `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`.
- Use semantic elements such as `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`.
- Build a clean page structure that improves readability and accessibility.
- Understand the role of meta tags and page titles in browser rendering.

### Forms and input controls

- Create forms with `input`, `textarea`, `select`, `checkbox`, `radio`, and `file` elements.
- Use validation attributes such as `required`, `minlength`, `maxlength`, `min`, `max`, and `pattern`.
- Group related fields using `fieldset` and `legend`.
- Practice common form patterns for user registration and feedback collection.

### Accessibility and labels

- Connect labels to inputs using `for` and `id` attributes.
- Use implicit labels by wrapping the input inside a `<label>` element.
- Add `aria-label` when a visible label is not available.
- Use meaningful `alt` text for images and skip decorative images with `alt=""`.
- Understand how broken image sources fall back to the alternate text.

### CSS fundamentals

- Work with selectors, classes, IDs, pseudo-classes, and pseudo-elements.
- Understand the CSS box model, spacing, colors, fonts, and responsive units.
- Use CSS variables for reusable values and design consistency.
- Learn the importance of selector specificity and how the cascade works.

### Layout and responsive design

- Build one-dimensional layouts using Flexbox.
- Create two-dimensional page layouts using CSS Grid.
- Use media queries to create responsive layouts for smaller screens.
- Explore how layout and spacing affect page structure and readability.

### Practice files in this folder

- `DocumentSkeleton.html` - basic HTML page structure
- `SemanticElements.html` - semantic HTML examples for blog content
- `ElementsDemo.html` - additional HTML element examples
- `FormExample.html` - registration form with form controls and validation
- `LabelForFeild.html` - correct and incorrect label patterns for accessibility
- `feedback.html` and `feedback.css` - accessible workshop feedback form
- `css-basics.html` - CSS selectors, units, box model, and variables
- `flexbox-1D.html` - one-dimensional Flexbox layout example
- `Grid-2d.html` - two-dimensional CSS Grid layout example
- `media-quries.html` - responsive design examples with media queries
- `AltText.Html` - image accessibility and alt text examples
- `address.feature`, `boundary_values.feature`, `customer_login.feature`, `discount_code.feature` - Gherkin scenarios for validation and user workflow testing

## Learning outcome

By the end of this day, the focus was to create accessible and visually structured pages that are easy to read, easy to navigate, and easier to test.
