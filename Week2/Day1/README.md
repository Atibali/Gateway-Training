# Week 2: Day 1 - Browser Tools, HTTP, and JSON

Day 1 covers practical browser inspection and HTTP/API exercises. The screenshots in this folder capture the examples and results.

## Topics covered

### Browser developer tools

- Inspect a responsive website using device emulation.
- Explore the Network panel, including Fetch/XHR requests, request headers, cookies, and resource timing.
- Use the Elements panel to inspect page structure and the Console to evaluate JavaScript and query the DOM.
- Review application storage, including cookies and local/session storage.

### Network and HTTP

- Resolve a hostname with `nslookup` and check connectivity with `ping`.
- Make HTTP requests with `curl` and inspect response headers and JSON bodies.
- Compare GET requests with different paths and query parameters.
- Observe a DELETE request and its response.

### APIs and JSON

- Retrieve posts and comments from JSONPlaceholder, including a post by ID and posts filtered by user ID.
- Retrieve paginated product data from DummyJSON using `limit` and `skip` query parameters.
- Use the browser `fetch` API and parse a JSON response.
- Convert JavaScript objects to JSON with `JSON.stringify` and back with `JSON.parse`.
- Validate and format JSON with an online JSON validator.
