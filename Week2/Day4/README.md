# Week 2: Day 4 - TypeScript, DOM, and Playwright

Day 4 covered TypeScript fundamentals, browser DOM interaction, and introductory browser testing with Playwright.

## Topics covered

### TypeScript fundamentals

- Add types to variables, arrays, tuples, enums, function parameters, and return values.
- Practice optional and default parameters, arrow functions, and `never` return types.
- Define and use interfaces, abstract classes, and classes.
- Explore class members with `public`, `private`, `protected`, and `readonly` access.
- Shape and transform data with TypeScript types.

### Browser DOM

- Select individual and multiple elements with common DOM selector APIs.
- Read and update element text, HTML, attributes, styles, and classes.
- Create and append elements to a page.
- Respond to click, input, and keyboard events, and remove event listeners.

### Playwright

- Write browser tests with Playwright's `test` and `expect` APIs.
- Navigate to a page, locate elements by role, interact with them, and assert page content.
- Practice basic assertions against user-object data.

## Practice files in this folder

- `basic-types.ts`, `other-types.ts`, and `functions.ts` - TypeScript types and functions
- `shape-interface.ts`, `abstract-class.ts`, and `account-class.ts` - interfaces, abstract classes, and access modifiers
- `shaping-data.ts` - shaping data with TypeScript
- `selecting-elements.html`, `updating-page.html`, and `handling-events.html` - DOM selection, updates, and event handling
- `async-await-login.js` and `objects.js` - JavaScript practice examples
- `tests/example.spec.ts` and `tests/objects.spec.js` - Playwright test examples

## Learning outcome

By the end of this day, the goal was to apply TypeScript types to everyday code, interact with browser pages through the DOM, and write basic automated browser tests.
